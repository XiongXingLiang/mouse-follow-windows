# Third-party components

This application uses Python (PSF), Tcl/Tk, NumPy (BSD), OpenCV (Apache-2.0), python-mss (MIT), Pillow (HPND), cryptography (Apache-2.0/BSD), and a PyInstaller-built bootloader (GPL with its bootloader exception). Each component retains its own license and notices. The build environment resolves the concrete package versions; consult their bundled metadata and upstream distributions for complete terms.

Game UI fragments in follower/assets are used only as recognition templates; game artwork remains with its respective rights holders.
