# 管理员授权签发

## 交付给使用者
只发送 `MouseFollower.exe` 和用户说明；不要发送管理员工具、私钥或整个 GitHub 仓库。

## 签发激活码
1. 双击 `LicenseIssuer.exe`。
2. 点击“载入原私钥”，选择部署时生成的 `owner-private.pem`。
3. 粘贴使用者设备码，选择永久、30 天或 3 天。
4. 点击“生成激活码”，复制并发给对应使用者。

限时从签发时刻开始。永久没有到期时间。每个码绑定一台设备，不能用于其他设备。重复签发体验码由你决定；客户端不会自动赠送新的试用期。

## 当前部署密钥
本项目的公钥位于 `follower/assets/license-public.pem`，可以放进私有仓库和客户端。
签发私钥由部署者在本机单独保管，未上传到 GitHub、未嵌入任何 exe。请离线备份。丢失后无法给已分发的客户端继续签发新码；更换密钥需要重建客户端。

首次部署工具中的“生成密钥”仅用于建立另一套全新部署，不能用于给当前客户端随意更换签发密钥。生成新密钥后，需要将配套公钥放入 `follower/assets/license-public.pem` 并重新构建。

## 安全边界
此版本完全离线，不需要激活服务器，也不上传截图或设备原始标识。设备码是本机标识的哈希。授权内容用 Ed25519 签名，客户端只持有公钥。

离线客户端无法远程撤销已签发授权，且不能绝对阻止专业修改客户端、克隆机器标识、清除本地状态后修改时钟等绕过方式。程序用 Windows DPAPI 保护本地状态，并检查运行中的到期和时间回拨，但不将它描述为不可破解。需要更严格的撤销和计时保证时，应增加联网授权服务。

## Windows 构建
私有仓库 Actions → Build Windows EXE → 选择成功运行：
- `MouseFollower-Windows-x64`：发给使用者。
- `LicenseIssuer-OwnerOnly-Windows-x64`：你保管。
- `SHA256SUMS`：文件校验值。

管理员工具和使用者客户端是两个独立产物。构建任务测试签名、防篡改、到期、绑定设备、检测和坐标转换，并启动 exe 的自检模式。CI 自检不会接管构建机鼠标；真实 Windows 游戏跟随还需要在你的游戏环境验收。
