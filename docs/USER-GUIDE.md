# 使用说明

支持 Windows 10 / 11，64 位。解压后双击 `MouseFollower.exe`，不需要安装 Python。

1. 首次启动，点击“复制设备码”，发送给软件提供者。
2. 将收到的激活码粘贴到“导入激活码”。支持永久、30 天、3 天体验。
3. 选择游戏所在的显示器，点击“开始监测”。默认只预览，不移动鼠标。
4. 确认预览能识别目标后，勾选“启用真实鼠标跟随”，再点击“开始监测”。窗口自动最小化，以免遮挡游戏。
5. 小游戏窗口和初始白色目标出现后开始跟随；画面消失、目标不确定、授权到期或出现结束提示时停止移动。
6. 按 `Esc` 紧急停止；按 `F8` 暂停或恢复。关闭软件即停止所有控制。

自动识别失败时，使用“手动框选画面”，只框小游戏内部石头区域，不包含标题和底部字幕。区域坐标按所选显示器计算。游戏窗口移动后需要重新框选；自动识别模式会重新寻找窗口。

目标必须先以白色出现，透明后才启动软件可能无法确定目标身份。截图识别要求游戏画面可见，不要用其他窗口遮挡。鼠标跟随只移动指针，不自动点击。

许可证绑定当前 Windows 设备。有效期从签发时起连续计算，不是累计使用时长。卸载或重启不能重置同一激活码的到期时间。系统重装、设备码变化时向提供者申请重签。

匹配分数并不是准确率。识别错误时立即按 Esc 停止。

## 性能版 2026.10.30

状态栏显示识别耗时与实际循环 FPS；FPS 统计包含截图、识别等工作，不等于视频播放帧率。打开“开始监测”后约一秒开始更新统计。透明阶段通常比白色阶段更慢。

若仍然跳动，先按 Esc 停止，再提供状态栏 FPS 和识别毫秒数。运行日志位于 `%LOCALAPPDATA%\MouseFollower\app.log`。手动框选只框小游戏内部区域，游戏移动或改变缩放后重新框选。
