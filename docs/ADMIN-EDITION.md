# 管理员永久自用版

解压后双击 MouseFollowerAdmin.exe，无需提供设备码，无需激活码，永久使用，无需联网授权。

这是独立的管理员自用程序，不是 Windows 的“以管理员身份运行”，通常不需要系统管理员权限。它不改变使用者客户端的授权要求。

1. 默认预览模式，点击“开始监测”。
2. 确认识别正常后，勾选“启用真实鼠标跟随”，再次开始。
3. Esc 紧急停止；F8 暂停或恢复。

只有管理员版免激活。请不要把这个 exe 发给普通使用者：拿到此版本的人也可以永久使用。

画面识别和跟随算法与普通版一致；Windows 实际游戏中的识别和鼠标移动仍需要现场测试。

性能版 2026.10.30 在窗口标题标明“性能版 10.30”，状态栏显示识别毫秒数和实际 FPS。若仍卡顿，请先用预览模式查看这两个值。日志位于 `%LOCALAPPDATA%\MouseFollower\app.log`。
