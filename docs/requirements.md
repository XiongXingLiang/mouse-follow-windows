# Windows 鼠标跟随工具

用户要求：
1. 当小游戏画面出现时，调用真实鼠标跟随目标。
2. 双击运行的 Windows exe，由 GitHub 构建。
3. 由所有者授予永久、30 天或 3 天权限。

默认实现选择（等待用户对授权模式的回复）：离线签名激活码，绑定本机设备码；限时从签发时计算。永久授权无到期时间。私钥与客户端、仓库、构建产物完全分离。只分发公钥。

运行方式：激活后主动点击开始监测；随后自动检测游戏窗口、初始白色目标并跟随。Esc 紧急停止；F8 暂停或恢复。游戏消失、结束提示、检测不确定或权限失效时停止移动鼠标。提供仅预览模式，真实鼠标接管需要明确启用。

范围限制：支持该游戏窗口的标题栏模板及可校准画面；多显示器物理坐标与 DPI 适配。跟踪为上一阶段算法的实时适配，不保证跟踪准确率。没有服务器的离线授权不能做到远程撤销，也不能绝对防止客户端补丁或系统时间回拨。
